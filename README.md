# 국어 놀이터 · 크롬북 2대 운영용

한국글로벌중학교 · 2026 시흥 AI+X 미래교육 페스타 Zone 2

## 1. 구글 시트와 Apps Script 준비

1. 행사 운영 계정으로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 지우고 이 폴더의 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. 편집기 위의 함수 목록에서 **setupScores**를 선택해 **실행**하고, 운영 계정에서 권한을 승인합니다. 시트에 **국어놀이터 점수** 탭이 생깁니다.
4. Apps Script의 **프로젝트 설정 → 스크립트 속성**에서 **SCORE_SYNC_TOKEN** 값을 복사해 둡니다. 이 값은 다음 단계에서 Netlify에 입력합니다.
5. **배포 → 새 배포 → 웹 앱**을 고릅니다. 실행 계정은 **나**, 액세스 권한은 로그인 없이 접근할 수 있는 **모든 사용자**로 선택합니다. 배포 후 끝이 **/exec**인 웹 앱 URL을 복사합니다.

시트 공유 설정은 비공개로 유지합니다. Apps Script는 Netlify 서버가 보내는 토큰을 확인한 뒤에만 시트를 읽거나 씁니다. 학교 계정에서 로그인 없는 웹 앱 배포가 제공되는지 확인하세요.

## 2. Netlify에 웹앱 배포

1. ZIP을 풀고 `netlify.toml`, `public`, `netlify`가 보이는 프로젝트 폴더의 내용을 Git 저장소에 올립니다.
2. Netlify에서 **Add new project → Import an existing project**로 저장소를 연결합니다. 이 프로젝트에는 빌드 명령이 필요 없습니다. `netlify.toml`이 공개 폴더와 Functions 폴더를 지정합니다.
3. Netlify 프로젝트의 **Environment variables**에서 두 값을 추가합니다. 범위를 고르는 메뉴가 있으면 Functions에서 사용할 수 있게 설정합니다.

   | 이름 | 값 |
   | --- | --- |
   | `SCORE_SCRIPT_URL` | 1단계에서 복사한 Apps Script **/exec** URL |
   | `SCORE_SYNC_TOKEN` | 1단계에서 복사한 스크립트 속성 값 |

4. 환경 변수를 저장한 뒤 **Deploys → Trigger deploy**로 재배포합니다. 서버 함수가 포함되어야 하므로 Git 연결 배포 또는 Netlify CLI를 사용합니다.
5. 배포 주소 뒤에 `/.netlify/functions/scores`를 붙여 엽니다. 새 시트라면 `{"ok":true,"records":[]}`가 표시됩니다. `not_configured`이면 환경 변수 두 개와 재배포 여부를 확인합니다. `not_authorized`이면 양쪽 토큰이 같은지 확인합니다.

Apps Script 코드를 수정한 뒤에는 기존 배포를 편집해 **새 버전**으로 갱신하면 같은 /exec 주소를 계속 쓸 수 있습니다.

## 3. 크롬북에서 운영

- **게임용**은 Netlify HTTPS 주소를 엽니다. **전광판용**은 같은 주소 뒤에 `/leaderboard.html`을 붙여 엽니다. 두 대 모두 게임을 하는 경우에는 같은 게임 주소를 엽니다.
- 게임을 마치고 별명을 등록해 시트에 행이 생기고, 다른 기기의 순위판에도 반영되는지 확인합니다. 순위판은 7초마다 상위 10명을 불러옵니다. 동점일 때는 먼저 등록한 기록이 위에 표시됩니다.
- 끝말잇기는 매 차례 **마이크로 말하기**를 누르고 브라우저가 듣기 시작하면 10초가 흐릅니다. **키보드로 입력**을 고르면 입력창이 열릴 때 시작합니다.
- 뽀랭이가 이기면 머리 위에 L 손 모양을 만들고, 낮은 옆차기와 양발을 모으는 점프를 왼쪽·오른쪽으로 번갈아 춥니다. **L 춤 다시 보기**로 처음부터 재생할 수 있습니다.
- 일시적으로 연결이 끊기면 제출 대기 기록을 브라우저에 저장합니다. 게임 페이지를 열어 둔 상태에서 연결이 돌아오면 다시 전송하고, 같은 제출은 한 번만 저장합니다.
- 시트에는 제출 ID, 별명, 점수, 난이도, 등록 시각을 저장합니다. 촬영 사진, 추정 나이, 음성은 점수 기록에 포함되지 않습니다. 테스트 기록은 운영자가 시트의 데이터 행을 지우면 됩니다. 첫 행의 제목은 유지합니다.
- 점수는 기존 게임이 브라우저에서 계산합니다. 서버에서 값의 형식과 범위는 확인하며, 대회용으로 점수를 검증하는 기능은 별도로 구현해야 합니다.

## 나이 추정이 안 될 때

1. 게임용 크롬북의 **설정**에서 Gemini API 키를 저장하고 **오프라인 모드 사용**을 끕니다. 키는 게임을 실행하는 각 크롬북의 브라우저에 저장됩니다. Netlify의 점수 연동 변수와는 별개입니다.
2. **사진 찍기**를 누르면 캡처한 화면이 멈추고, Gemini가 얼굴의 대략적인 나이를 추정합니다. 13세 미만이면 초등, 13세 이상이면 중등 난이도를 제안합니다. 추천은 화면에서 바꿀 수 있습니다.
3. 촬영은 됐는데 결과가 안 나오면 사진 옆에 표시되는 안내에서 키·권한, 사용량 한도, 응답 지연, 얼굴 확인 실패를 구분할 수 있습니다. 카메라 자체가 안 열리면 크롬 주소창 왼쪽의 사이트 설정에서 카메라를 허용해 주세요.
4. 사진을 건너뛰면 초등·중등 난이도를 직접 고릅니다. 마이크가 어려운 경우 끝말잇기의 **키보드로 입력**을 사용합니다.
